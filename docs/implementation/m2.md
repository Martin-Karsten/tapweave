# M2 implementation status

Status: independent primitives implemented and tested. **Full M2 is incomplete.**
This report describes the original primitive increment; see [session integration](m2-sessions.md)
for the subsequent production APIs. Tapweave is not yet browser-playable.
The original primitive increment did not advertise production simulation or
replay capabilities. See the [remaining acceptance work](m2-plan.md).

This increment was developed separately while M1 was unfinished and imported
into the main worktree on 2026-09-12 after M1 completion. The [current status](../status.md)
records the completed M0/M1 gates. The subsequent session integration consumes
those final preparation contracts.

## Implemented

- Stable production result identifiers and explicit hit/miss, score, accuracy,
  combo, tick and bonus properties. Legacy padding result 99 is rejected.
- Allocation-free scoring over explicit judgement streams: perfect maxima,
  nested/ignored result counts, combo/highest combo, accuracy numerator and
  denominator, normalized score, midpoint-even rounding, rank and failure guard.
- Pinned hit-window predicates and forward-only spinner history preserving f32
  intermediates. These are primitives, not full circle/spinner state machines.
- Bounded drain-rate calibration over explicit maximum-health increases and
  break ends, preserving pinned operation order and search termination.
- Caller-buffer event heap and input ring: phase/component/sequence ordering,
  retained future events, output backpressure, transactional malformed/late batch
  rejection and consumed-slot reuse. Borrowed input/output buffers must be
  disjoint from queue storage; overlap is rejected before mutation. These are
  not a complete session scheduler.
- Replay identity/frame validation, equal-time interpolation semantics and an
  allocation-free internal v2 codec with canonical little-endian values,
  full u64 sequences, checked sizes, reserved-byte validation and SHA-256.
  Corruption/failed decode preserves the caller's prior destination.
- Separate simulation trace schema/native/WASM transports and a real upstream
  reference adapter. Round-trippable float serialization avoids precision loss
  in the pinned Odin JSON library's default decimal formatting.

The standalone codec carries a supplied final result digest; the integrated
session computes its own judgement digest for comparison. Recording, playback and
initial-checkpoint resimulation live in the session, not the codec. See the
[internal replay contract](../../engine/replay/README.md).

## Source findings and regression correction

**Review corrections (2026-09-12).** Input submission and event draining now
reject exact or partial buffer overlap transactionally, using the same shared
address-difference check as the replay codec. Regression tests cover wrapped
rings, overlap in both directions, adjacent/empty slices, unchanged state on
rejection and subsequent draining. See the [queue contract](../../engine/simulation/README.md).

Replay interpolation now follows framework Vector2 f32 time/vector arithmetic.
The earlier f64/subnormal-preserving implementation was a local assumption and
has been corrected against executable upstream replay-handler probes. Intervals
that overflow f32 are rejected before publishing a replay.
Codec tests additionally recompute checksums after malformed payload mutations
to reach identity, ordering, numeric, action/flag and reserved-byte validation;
each rejection preserves the destination, including malformed second frames.

Result properties use named fields. The new Odin packages, tests, transports,
fixture scripts and reference adapter use expressive local names and expanded
control flow. Difficulty-range arithmetic is shared by preparation, hit windows
and drain calibration, retaining the original operation order. AGENTS.md requires
a naming review of changed files before delivery.

Validation after these corrections passed `npm --prefix engine test` and
`npm --prefix engine run test:simulation:upstream` on macOS arm64 with Node 24
and the pinned compiler: 14 allocation-tracked M2 groups, 100 byte-identical M2
native/WASM fixtures and 67 exact pinned component comparisons. The full local
suite also retains 88 decoder, 74 geometry plus 4 failure, and 101 preparation
fixtures. The four added fixtures are local contract regressions, not upstream
acceptance. Historical finding hashes remain unchanged; current generated
reports are under `engine/artifacts/simulation/`. Full M2 remains incomplete.

**Circle deadline correction.** The earlier prose incorrectly made +400 ms the
automatic circle miss deadline. Pinned `OsuHitWindows.ResultFor` returns Miss
through ±400 ms; `CanBeHit` instead becomes false strictly after the Meh window.
`DrawableHitCircle` uses that predicate for automatic misses. H06 primitive
observations cover exact/adjacent boundaries; full drawable/input policy remains
unverified here. Reference prose and the roadmap boundary catalogue are corrected.

**Drain boundary caution.** Pinned calibration skips the interval when a break
end is crossed; gameplay derives broader no-drain periods from surrounding hit
objects. Default failure checking is not simply a continuous zero-crossing:
bonus maxima and IgnoreHit are exempt in `DrainingHealthProcessor`. H09's full
player/failure adapter remains necessary to validate the implemented session failure events.

**Existing WASM regression order.** The copied preparation ABI test pre-grew
memory before the foundation detachment probe, causing its growth assertion to
fail without a foundation leak. Preparation now runs after the foundation
50-cycle growth/plateau assertion. Both tests retain their assertions.
