# M3 independent browser foundation

**M3 is not complete and Tapweave is not playable.** The latest
[W01 ledger](#w01-implementation-ledger--compact-output-and-active-projection) records
compact output and the W03 active-projection foundation. Earlier sections retain
increment-specific implementation and validation history. Play remains disabled;
the [M3 plan](m3-plan.md) owns remaining work and exit gates.

## Implemented

- Separate Node 24 browser package with exact fflate 0.8.3 / Playwright Test 1.63.0
  lockfile, framework-free UI, static build and loopback development server.
- A production-only WASM entrypoint without test trace exports.
- One generated JavaScript ABI reader/writer shared by browser and TypeScript
  consumers, including checked spans and named bootstrap transport offsets.
- Real ABI map preparation and owned descriptor copies, typed errors, lossless
  handles, memory-view reacquisition and explicit release/disposal.
- Local archive/loose-file loading and difficulty selection. ZIP validation covers
  paths, ambiguity, structure/ranges, compression support, quotas and CRC.
- Transactional replacement and asynchronous generation cancellation. Failed
  replacement preserves the previous valid map and its asset scope. Decoded music
  is cached across difficulty changes within a source and released with the scope.
- An independent audio anchor and execution service for explicit test events,
  voice/ramp/epoch cleanup, late-event policy and bounded queues.
- An independent physical-input aggregation/buffering service with receipt-time
  transform snapshots, retained failed submissions and release-all behavior.
- An Odin playfield transform and exact native/WASM local test transport.
- A shared round-trip float marshaler for simulation/presentation test evidence.
- Diagnostics export, responsive layout and a browser CI job.

The input/audio services are not wired into gameplay. Their explicit JS fixtures
are not production protocol definitions or upstream observations. Source-specific
sample selection, loops/ramps and object presentation remain Odin responsibilities.
The initial transform does not yet expose a production presentation capability.

## Browser foundation review fixes

Pending selection candidates now have explicit ownership. Replacement and disposal
release their engine maps and unshared asset scopes immediately, even while a
browser decode is still pending. Completion of a stale request cannot release the
current candidate or the active difficulty's shared source. Browser decoder peak
allocation and cancellation limitations above still apply.

ZIP data descriptors, with or without signatures, must match central-directory
CRC and sizes; their bytes participate in entry overlap checks. Missing, truncated
or inconsistent descriptors reject before extraction.

Audio enqueue validates capacity against only events surviving epoch replacement.
Malformed or oversized batches still leave the prior state intact. A pump failure
cancels pending playback and all active/retiring voices before propagating the
error, preventing a rejected start from permanently blocking later loop stops.
This is an execution failure requiring caller recovery, not hitsound selection or
voice stealing policy.

Regression coverage includes deferred-decode replacement/disposal and shared-source
preservation, descriptor variants/corruption, voice exhaustion and epoch capacity.
No gameplay, ABI or upstream-acceptance capability is added.
