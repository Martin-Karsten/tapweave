# M0 implementation status

M0 has started in [`engine/`](../../engine/README.md). It is not yet at its compatibility exit gate. Historical ABI v1 spikes remain local and are excluded from this public repository.

## Implemented increment

- Separate acyclic Odin foundation packages with no spike or browser dependency.
- Two-pass raw decoder for required versions, with owned text/records, typed errors, checked sizes, and bounded resources.
- Prepared-storage reference counting, reusable zeroing arenas, and handle-table ownership/generation primitives.
- Shared native/WASM decoder traces, JSON Schema, exact diff CLI, deterministic fixture builder, and hashed acceptance reports.
- Pinned source/licence manifest verifier and a .NET reference-host skeleton that explicitly refuses to emit an oracle until adapters are implemented.
- Standalone pinned compiler setup and a public foundation CI workflow.

## Validation performed

`npm --prefix engine test` passes seven allocation-tracked Odin test groups and 31 native/WASM byte-identical decoder fixtures. Cases include required/rejected versions, numeric failures, stable ordering, BOM/Unicode, NaN marker handling, and the 10,000-object quota edge. Native tests include injected allocation failure, failed candidates preserving an existing map, checked arithmetic overflow, ownership/type mismatches, stale generations, slot retirement, and 50 small/large storage cycles with four retained session arenas and reset loops.

A historical local spike regression also passed before publication. That suite is not included in this repository and is not required by public CI.
