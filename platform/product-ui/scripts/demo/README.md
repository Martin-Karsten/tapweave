# Demo beatmap provenance

The `tapweave-demo.osz` served from `public/demo/` is an original work made
for Tapweave. It is generated deterministically by
[`../generate_demo.mjs`](../generate_demo.mjs); nothing here is downloaded,
sampled, or copied from osu!, ppy, or any third-party song, sample pack, or
beatmap. Both the beatmap layout and the music are authored as constants in
the generator: the map is a hand-placed beginner arrangement, and the audio is
synthesized from sine oscillators and a seeded noise generator (no recorded
material at all).

## Terms

- The generator source (`scripts/generate_demo.mjs`) is part of this
  repository and covered by the repository's MIT license (see the root
  `LICENSE`).
- The generated demo assets (`tapweave-demo.osu`, `tapweave-demo.wav`, and
  the packaged `tapweave-demo.osz`) may be redistributed and used with the
  demo build under the same MIT license, with the attribution note
  "Tapweave demo beatmap — generated by Tapweave".

## Verification

`manifest.json` is tracked and records the sha256 and byte length of each
generated output. `npm run prepare-assets` regenerates the archive and fails
on any mismatch, so a nondeterministic generator or an unrecorded intentional
change cannot ship silently. After an intentional demo change, regenerate the
manifest:

```sh
node scripts/generate_demo.mjs --update-manifest
```

and commit the manifest together with the generator change.

Generated archives are never committed: `platform/product-ui/public/` is
gitignored, and `prepare-assets` (run by `dev`, `build`, `preview`,
`test:browser`, and `test:gates`) recreates the archive before it is served.
